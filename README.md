# 현장 유류대 대조표 생성기 · 점검기

건설 현장의 **장비작업일보**와 **경유사용집계표** 엑셀로 유류대 및 장비비 대조표를 만들고 점검하는 웹페이지입니다.
엑셀 파일은 브라우저 안에서만 읽으며 서버로 전송하지 않습니다.

| 페이지 | 하는 일 |
|---|---|
| `index.html` — 유류대 대조표 생성기 | 작업일보 + 경유사용집계표 → 월별 대조표, 장비별 평균(월별 유류사용량·시간당 사용량), 그래프가 든 엑셀 생성 |
| `checker.html` — 현장 유류대 점검기 | 완성된 정리 엑셀의 수식·숫자 불일치, 이상 주유, 누락 장비 점검 |

## 사용법
1. 페이지를 열고 엑셀(.xlsx)을 끌어다 놓습니다.
2. 결과를 확인한 뒤 **엑셀 만들기 / 결과 엑셀로 받기** 버튼으로 내려받습니다.

## 읽는 양식
- 경유사용집계표: A열에 `장비명 / 회사 / 규격 / 성명 / 번호 / 날짜` 머리행, 아래로 일자별 수량·금액, `소 계` 행
- 장비작업일보: `차량번호` 머리행, 1~15일 / 16~31일 두 줄, `수 량(시간)`, `단가`, `금 액`, `비 고`(예: "4월분")
- 시트 이름이나 A1 칸에서 달(예: `26.8월`)을 읽습니다.

## 사용한 라이브러리 (CDN)
SheetJS 0.18.5, ExcelJS 4.4.0, JSZip 3.10.1
